# Shetkari Irrigation – Business Website

A responsive marketing website for a drip and sprinkler irrigation equipment business.

## Features

- Single-page layout with Home, About, Benefits, Products, Why Us and Contact sections
- Contact section with WhatsApp, Facebook and Instagram links
- Responsive layout for mobile, tablet and desktop
- Full favicon set for browsers and mobile home screens

## Tech stack

- HTML5
- CSS3 (`assets/css/styles.css`)
- JavaScript (`assets/js`)
- Google Fonts

## How to run

No build step. Clone the repo and open `index.html` in a browser.
